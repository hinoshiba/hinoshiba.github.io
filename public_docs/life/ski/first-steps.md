### 1\. 滑る前の事前

1. <a id="b-1532fd7b67a8802e80decc62eb979b06"></a>板の置き方

   1. <a id="b-1532fd7b67a88043bca1e8a658f7d10d"></a>山に並行に置く

   1. <a id="b-1532fd7b67a8805b930bd0202416f3a4"></a>ストッパーが出るので、外れても安全ということを理解する

1. <a id="b-1532fd7b67a880168492df9fb0097358"></a>板の履き方

   1. <a id="b-1532fd7b67a880d18dd5d26c2dce13d4"></a>ビンティング（留め具）についている雪を蹴る

1. <a id="b-1532fd7b67a880a7995cf516f1fb20db"></a>板の外し方

   1. <a id="b-1532fd7b67a88095b6a9efcd380ccd19"></a>ビンティングをストックで押す

   1. <a id="b-1532fd7b67a880edb092d14eb5ec59c5"></a>ビンティングをストックで蹴る

1. <a id="b-1532fd7b67a880b6b742f31f09097c2b"></a>歩き方

   1. <a id="b-1532fd7b67a880d5a4d7c832b217af69"></a>片足だけスキー板をつけて、歩く練習

      1. <a id="b-1532fd7b67a880cdab25e41061d1049c"></a>つま先を少し外側にして、インエッジで歩く

   1. <a id="b-1532fd7b67a880a79169cb23fc64fae3"></a>両方スキー板をつけて歩く

      1. <a id="b-1532fd7b67a88031881ffe702f13a15a"></a>片足と同じ

   1. <a id="b-1532fd7b67a880ef8b6ddc9f8dba04ab"></a>両足揃えて、山に対して並行に歩く

      1. <a id="b-1532fd7b67a88089b9ace72a0ea1253e"></a>カニさん歩きで山を登る

   1. <a id="b-1532fd7b67a880ebbb3fec61397709fa"></a>方向転換\(地上で少しずつ回転する\)

      1. <a id="b-1532fd7b67a880929c3df1e5048d1ff0"></a>肩幅で少しずつ足を回す

      1. <a id="b-1532fd7b67a8802b9654d262d86f47f4"></a>開きすぎるとスキーがバッテンになってしまうので注意

1. <a id="b-1532fd7b67a880e3a8edc66d20f9572d"></a>プルークのポーズの練習

   1. <a id="b-1532fd7b67a88019bf8dcc681bdfd4be"></a>インエッジを使って雪を掴む

1. <a id="b-1532fd7b67a880b790faef4a3502ac31"></a>足を揃える練習

   1. <a id="b-1532fd7b67a8803888a7c25546e1646e"></a>エッジを建てず、スキーをすっと揃える

   1. <a id="b-1532fd7b67a88021aac1c0e5b4daa71d"></a>滑走状態プルーク\(ボーゲン\) だと両足同時にエッジを建てないのは最初難しいので、片足ずつやる

1. <a id="b-1532fd7b67a880f68325d461f1dbc977"></a>転ぶ練習

   1. <a id="b-1532fd7b67a8804d9464eb2c25673885"></a>基本的に、プルークの状態から女の子座りになってはいけない

      1. <a id="b-1532fd7b67a8801798c2fa3b2d314e73"></a>立てなくなる。もしこんがらがって、この形になる場合、スキーを外す

   1. <a id="b-1532fd7b67a880d38302fdc3e94eddf6"></a>プルークから両足揃えの形になり、膝を少し曲げながら、お尻から、山側に倒れる

      1. <a id="b-1532fd7b67a880f8b2b1d0744ba483ef"></a>上半身から倒れず、膝→お尻→上半身と　崩れるように倒れる

<a id="b-1532fd7b67a880dc8077f136c406108c"></a>

### 2\. 滑る直前の練習

1. <a id="b-1532fd7b67a880a5af3acf5b2e62946f"></a>ブレーキの練習

   1. <a id="b-1532fd7b67a8807399a6d0aa8b812d03"></a>ストックで少し進ませて、プルーク（ハの字）を作る

1. <a id="b-1532fd7b67a88026986dc3bc73884b56"></a>傾斜で止まる: 1

   1. <a id="b-1532fd7b67a880808d1cc6e11ccb7169"></a>カニさん歩きで、少し傾斜を登り、ブレーキ状態で、止まる

1. <a id="b-1532fd7b67a880efa00cd460973ec51c"></a>傾斜で止まる: 2

   1. <a id="b-1532fd7b67a88025b8e0e08e0a127154"></a>カニさん歩きで、少し傾斜を登り、プルーク。プルークから少し、足をそろえて少し滑走。またプルークで止まる

1. <a id="b-1532fd7b67a880989ae6c885747efb96"></a>左右に曲がる

   1. <a id="b-1532fd7b67a880e4a370d8f1247bd850"></a>傾斜を少し登り、プルーク

   1. <a id="b-1532fd7b67a8806eb8a5dc4119965457"></a>少し入れている力を緩め、プルーク状態で前進

   1. <a id="b-1532fd7b67a880ecb4b6d98859ff4999"></a>片足に力を入れると曲がることができる

   1. <a id="b-1532fd7b67a880609197d815871c810f"></a>山に対してS字を描くような順序で、右→左→右 と力を入れる

<a id="b-1532fd7b67a8807891c3c7e9aa7f24c4"></a>

### 3\. 滑る練習

1. <a id="b-1532fd7b67a88089bf9ffe29a3ff05f6"></a>リフトで移動

   1. <a id="b-1532fd7b67a8808084b5d923c3aebc32"></a>歩く&amp;ブレーキ ができていると、リフトの線で止まれる

   1. <a id="b-1532fd7b67a88085af15d5ffaf8bcf7c"></a>ストックが腹に刺さらないように注意

   1. <a id="b-1532fd7b67a8804b8696dddbb50c203f"></a>降りたら、人がいないところまで、プルーク状態を用いつつ移動

1. <a id="b-1532fd7b67a88009ba0ee2473c3c9aaf"></a>ボーゲン滑り

   1. <a id="b-1532fd7b67a880b39a1dd0ebebc5f6db"></a>左右に曲がりながら、プルークをキープしつつ、S字を描くように移動
