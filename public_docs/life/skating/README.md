### スケート場

#### 横浜銀行アイスアリーナ

- [横浜銀行アイスアリーナ｜トップページ](https://yokohama-icearena.jp/)

- 最寄駅: 東神奈川

- ロッカー: 100円

- 費用: 1350円

#### kose新横浜スケートセンター

- [KOSÉ新横浜スケートセンター \| 新横浜プリンスホテル](https://www.princehotels.co.jp/skate/shinyokohama/)

- 最寄液: 新横浜

- ロッカー: 300円

- 費用: 1200円\(セゾンカードクーポンあり\)

#### 明治神宮アイススケート場

- [明治神宮外苑アイススケート場\|都会の喧騒を忘れ最高の滑走体験\|東京\|関東](https://meijijingugaien-iceskating.com/)

- 最寄駅: 新国立競技場 / 千駄ヶ谷

- ロッカー: 100円

- 費用: 1600円\~ \(時期で値段変わる\)

#### 赤レンガスケート

- [アートリンク in 横浜赤レンガ倉庫](http://akarenga-artrink.yafjp.org/)

- 最寄駅: 関内 / 桜木町

  - 距離はあまり変わらない

- ロッカー: 100円

- 費用: 1500円\~ \(毎年値段違う/時期で値段変わる\)
