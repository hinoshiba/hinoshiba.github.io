- <a id="b-1482fd7b67a8801eb109d7066d1c3f46"></a>JRの駅の商業施設に、入浴施設がある

  - <a id="b-1482fd7b67a8808ca7dcc5900825b192"></a>スキー → サウナ → 帰宅新幹線 が、丸っと1日遊んでいい感じコース

  - <a id="b-1482fd7b67a880efb124edee9adcb762"></a>上記工程のためには、新幹線の出る、3h前には、ふもとまで戻ってくる形が吉

## 1\. 申し込み

<a id="b-1482fd7b67a880568e84dc2a558d6010"></a>

### 1\. 新幹線&amp;リフト券

- <a id="b-1482fd7b67a88055ba81d69394c35804"></a>ダイナミックレールパックが安い

  - <a id="b-1482fd7b67a88059832df39a6d649f9c"></a>キーワードは、 <code>JR ski ski ガーラ湯沢</code> とか。

- <a id="b-1482fd7b67a880819ae5fd7ac2f9b1b8"></a>新幹線は、到着時間を見る。8時に開くから、　7:58着とかがおすすめ

  - <a id="b-1482fd7b67a8801e96a6ea557c58246e"></a>快速的なやつで、所要時間が短いのあるから、出発時間じゃダメ

- <a id="b-1482fd7b67a88026ad2fcd4003de364b"></a>キャンペーンページが誕生しておらず、直接検索するのであれば、こういうノリ

### 2\. レンタル

- <a id="b-1482fd7b67a880dc80e7c592be202990"></a>事前申し込みURL

  - <a id="b-1482fd7b67a8809f85b9eec0812cdf57"></a>[https://gala\.co\.jp/winter/rental/](https://gala.co.jp/winter/rental/)

- <a id="b-1482fd7b67a880578ac1d6c4a1ee4064"></a>グローブとかは無いよ！

  - <a id="b-1482fd7b67a880489dfbeecf4372dbe3"></a>厚めの靴下、インナー、ゴーグル、ヘルメット、グローブ etcは必要に応じて

- <a id="b-1482fd7b67a880c0b3dee207b5b0c208"></a>サイズは、最悪当日変更できる

  - <a id="b-1482fd7b67a8806a9c92e72d5117502a"></a>ただし、物交換時には、再度、レンタルの列に並ぶ必要がある

  - <a id="b-1482fd7b67a880b0980bf881b448a1d0"></a>大人サイズだと、第一段階リフト登ったところでも交換できるから、一回すべってみて微妙だったら、上の休憩所で変えるとかも可能

## 2\. 事前準備

1. <a id="b-1482fd7b67a880368ab2fcd6c0585377"></a>JR券売機で、チケット発券しておく

   1. <a id="b-1562fd7b67a880c48de0d5a133c92065"></a>最寄りのJR  みどりの窓口や、新幹線対応の券売機で発券可

1. <a id="b-1482fd7b67a880d0b858f919b47a1d3a"></a>レンタル品のサイズ等を登録しておく

1. <a id="b-1482fd7b67a880fa8ae7e1e1038d7150"></a>リフト券の、QRコードを用意しておく

   1. <a id="b-1562fd7b67a88011872fcea9594845e4"></a>旅行工程表のQRコード付きPDFとして、えきねっとからDLできる

   1. <a id="b-1482fd7b67a8801881b3e0f2a23e40e1"></a>電波悪くて手間取らないように、スクショ

1. <a id="b-1482fd7b67a88047ba47cf132fe24f41"></a>レンタル品の、QRコードを用意しておく

   1. <a id="b-1482fd7b67a8800aafacdb5b8ab6c16d"></a>電波悪くて手間取らないように、スクショ

<a id="b-1482fd7b67a880b7aceef097185d634c"></a>

## 3\. 当日

1. <a id="b-1482fd7b67a88054a924d3119fe9763d"></a>降りたら、QRコードだして、リフト券を受け取る

   - <a id="b-1482fd7b67a8807f8874ca6786d89695"></a>人がいる受付っぽい窓口には行かない（左手奥に機械があって、QRコードかざせばおk）

1. <a id="b-1482fd7b67a880449f95feea625452d6"></a>レンタルの列に並ぶ

   - <a id="b-1482fd7b67a880578f96dfc0cbe9c03c"></a>列はどんどん伸びる。当日手書き申し込み勢がいる

   - <a id="b-1482fd7b67a880649543df616d9871eb"></a>設備の並び順の関係で、リフト券が先だが、すでにレンタルの列が伸びてきているのであれば、レンタルの列に並んじゃう

1. <a id="b-1482fd7b67a880bc99b7e34549229782"></a>ロッカー 1000円

   - <a id="b-1482fd7b67a8803c8e1ec01ef1773f3f"></a>何度も開けられる。結構でかい。2人で1つとかできそう

   - <a id="b-1482fd7b67a8801987b9fa57e2eab704"></a>荷物が小さすぎるのであれば、ロッカー借りない or ゴンドラ登った上にある休憩所の300円ロッカーを使う

     - <a id="b-1482fd7b67a88070b0f4f5dbb28882e1"></a>こちらは何度も開けられないので注意

1. <a id="b-1642fd7b67a8806f920ddb284c3cff34"></a>ゴンドラで上に上がる
